# Приглашение на той

Одностраничный сайт-приглашение на свадьбу или кыз узатуу: конверт с сургучной
печатью, таймер, стираемая дата, история пары, программа, место, дресс-код и
RSVP в Telegram. Две темы, кыргызский и русский языки.

Next.js (App Router), TypeScript, Tailwind CSS 4, GSAP.

## Запуск

```bash
npm install
npm run dev
```

Сайт откроется на http://localhost:3000. Страница http://localhost:3000/styleguide
показывает палитры и шрифты обеих тем рядом; в production её нет.

| Команда | Что делает |
| --- | --- |
| `npm run dev` | Режим разработки |
| `npm run build` | Production-сборка |
| `npm run start` | Запуск собранного сайта |
| `npm run typecheck` | Проверка типов |

## Новый заказ

Меняются только конфиг, фото и музыка. Код трогать не нужно.

1. **Конфиг** — `config/invite.ts`. Тема, языки, имена, дата и время, место,
   программа, история, дресс-код, музыка, RSVP, подпись студии. Тексты заказа
   пишутся сразу на двух языках: `{ ky: '…', ru: '…' }`.
2. **Фото** — положите файлы в `public/photos/` и укажите пути в конфиге.
   Подойдут JPG или PNG шириной около 1000 px; сайт сам отдаст гостю WebP
   нужного размера. Фото истории показываются в пропорции 4:5, фото зала — 3:2,
   лишнее обрезается по центру.
3. **Музыка** — замените `public/audio/theme.mp3`. Файл загружается только
   после тапа по конверту. Сейчас там синтезированная мелодия-заглушка.
4. **Telegram** — см. ниже.
5. **Деплой** — см. ниже.

### Темы

Поле `theme` в конфиге:

- `romantic` — айвори, пудровый розовый, шалфей; рукописные имена, бабочки и лепестки.
- `national` — кремовый, бордо, золото; орнаменты ою-оймо, имена прописными.

Цвета и шрифты тем лежат в `styles/themes.css`. Если меняете палитру, обновите
и её копии для иконки и картинки-превью в `config/themes.ts`.

### Стили и адреса

Кроме классики, приглашение собрано в других стилях. Каждый стиль живёт по
своему адресу и показывает тот же заказ из `config/invite.ts`:

| Адрес | Стиль |
| --- | --- |
| `/` | Классика: конверт с сургучом, темы `romantic` и `national` |
| `/minimal` | Минимализм: лист кальки над приглашением, тонкая антиква, календарь с обведённой датой |
| `/grotesk` | Гротеск: швейцарский плакат — огромные цифры даты, сетка, кобальт; табло, шторки на заголовках, салют |
| `/typewriter` | Машинопись: свадебная телеграмма — текст на наклеенных лентах печатается на глазах, штемпель с датой, цвета дресс-кода марками |
| `/editorial` | Эдиториал: свадебный номер журнала — обложка перелистывается, внутри линейки, буквица, программа с отточиями |

У каждого стиля свой корневой layout (`app/<стиль>/layout.tsx`): свои шрифты,
CSS, цвет панели браузера, иконка и картинка-превью. Код стиля лежит в
`designs/<стиль>/`. Логика общая для всех стилей: таймер (`lib/useCountdown.ts`),
форма RSVP (`lib/useRsvpForm.ts`), языки, музыка и фаза интро
(`components/providers/`).

### Имена с буквами ө, ү, ң

В рукописном шрифте темы `romantic` (Great Vibes) нет кыргызских букв ө, ү, ң.
Если такая буква есть хотя бы в одном имени, шаблон сам набирает оба имени
другим рукописным шрифтом, Bad Script: он проще по рисунку, зато буквы в нём
родные. В теме `national` все буквы есть, там ничего не меняется.

### Языки

`languages.available` задаёт список, `languages.default` — язык по умолчанию.
Если язык один, переключатель не показывается. Ссылку можно отправить сразу
на нужном языке: `https://ваш-сайт/?lang=ru`.

Тексты интерфейса (подписи кнопок, заголовки секций) лежат в `locales/ky.ts`
и `locales/ru.ts` и от заказа к заказу не меняются.

## RSVP в Telegram

Ответы гостей бот присылает в чат пары.

1. Создайте бота у [@BotFather](https://t.me/BotFather) и получите токен.
2. Напишите боту любое сообщение. Для группы: добавьте бота в группу и напишите там.
3. Откройте `https://api.telegram.org/bot<ТОКЕН>/getUpdates` и возьмите число из
   `"chat":{"id": …}`. У групп оно отрицательное.
4. Локально: скопируйте `.env.example` в `.env.local` и заполните
   `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID`. На Vercel: те же переменные в
   Project → Settings → Environment Variables.

`chat_id` можно указать и в конфиге (`rsvp.telegramChatId`), но переменная
окружения важнее, и через неё id не попадает в код сайта. Токен хранится
только в переменных окружения.

Если бот не настроен, гость при отправке увидит сообщение об ошибке, а в логах
сервера появится строка `[rsvp] Бот не настроен`.

## Деплой на Vercel

1. Загрузите проект в Git-репозиторий и импортируйте его в Vercel.
2. Добавьте переменные `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID`.
3. Если у приглашения свой домен, добавьте `SITE_URL=https://ваш-домен` — по
   нему строится ссылка на картинку-превью. Без своего домена не нужно.

Картинка-превью (её показывают WhatsApp и Telegram рядом со ссылкой) и иконка
вкладки собираются из конфига автоматически при сборке.

## Структура

```
app/
  (classic)/          классика: страница /, стайлгайд, иконка, картинка-превью
  minimal/            минимализм: страница /minimal, иконка, картинка-превью
  editorial/          эдиториал: страница /editorial, иконка, картинка-превью
  grotesk/            гротеск: страница /grotesk, иконка, картинка-превью
  typewriter/         машинопись: страница /typewriter, иконка, картинка-превью
  api/rsvp/           приём ответов гостей
components/           классика
  intro/              конверт и печать
  sections/           секции страницы, по файлу на секцию
  effects/            бабочки, лепестки, орнаменты, анимации на GSAP
  providers/          контент заказа, язык, фаза интро, музыка — общие для всех стилей
  ui/                 кнопка, секция, переключатель языка, кнопка музыки
designs/
  shared/             общее для стилей: приглашение под интро, эффекты появления, табло
  minimal/            минимализм: секции, шрифты, CSS
  editorial/          эдиториал: секции, шрифты, CSS
  grotesk/            гротеск: секции, шрифт, CSS
  typewriter/         машинопись: секции, шрифт, CSS
config/               invite.ts — контент заказа; types.ts — его схема
locales/              тексты интерфейса на двух языках
lib/                  дата, таймер, RSVP, Telegram, загрузка анимаций
styles/               токены и темы классики
public/               фото, музыка, текстура бумаги
assets/fonts/         шрифты для картинок-превью
```

## Производительность

- До тапа по конверту загружается около 410 КБ: HTML со встроенным CSS, JS,
  шрифты, текстура. Музыка и GSAP в первую загрузку не входят: музыка грузится
  по тапу, GSAP — отдельным чанком по первому касанию или через две секунды простоя.
- Фото отдаются через `next/image` в WebP и подгружаются по мере прокрутки.
- Бабочки, лепестки и таймер останавливаются, когда их секция ушла с экрана.
- При системной настройке «уменьшить движение» бабочки, лепестки и конфетти
  не создаются, остальные анимации отключены.

## Ограничения

- Нужен браузер не старше Chrome 111 / Safari 16.4 (март 2023): цвета заданы в OKLCH.
- На iPhone музыка включается сразу на полной громкости, без плавного
  нарастания: iOS не даёт сайту управлять громкостью.
- Лимит ответов RSVP (5 за 10 минут с одного адреса) приблизительный: счётчик
  хранится в памяти сервера, а не в общей базе.
