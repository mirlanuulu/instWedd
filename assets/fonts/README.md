# Шрифты для генерации картинок

TTF-копии шрифтов приглашения. Нужны только при сборке: из них рисуется
картинка-превью ссылки (`app/opengraph-image.tsx`). На сайт гостю они не
отдаются — там работают woff2 из `next/font` (см. `lib/fonts.ts`).

Источник: Google Fonts. Лицензия всех четырёх: SIL Open Font License 1.1,
она разрешает использование и распространение в составе продукта.

| Файл | Семейство |
| --- | --- |
| `CormorantGaramond-Medium.ttf` | Cormorant Garamond |
| `GreatVibes-Regular.ttf` | Great Vibes |
| `BadScript-Regular.ttf` | Bad Script |
| `Forum-Regular.ttf` | Forum |
