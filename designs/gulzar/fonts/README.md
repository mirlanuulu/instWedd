# Gulzar Script KG

Дополнение к рукописному Great Vibes, которым в «Гүлзаре» набраны имена.
В Great Vibes нет кыргызских букв, поэтому в этом файле только они:
ө ү ң Ө Ү Ң. Браузер берёт их отсюда, остальные буквы — из Great Vibes.

Буквы собраны из контуров самого Great Vibes, поэтому совпадают с ним по стилю:

- ө, Ө — «о» и «О» с перекладиной из дефиса;
- ү, Ү — «у» и «У» без петли хвоста, с прямой ножкой;
- ң, Ң — «н» и «Н» с хвостиком.

Пересобрать: `node build-kyrgyz.mjs GreatVibes-Regular.ttf GulzarScriptKG.ttf`
(исходник — `assets/fonts/GreatVibes-Regular.ttf`).
